## Episode 6: Figure 3 Hopf bifurcation loci

- Useful transcripts:
  - [Figure 3 Hopf planning](../../sessions/bs2026-figure3-planning/)
  - [Python augmented Hopf continuation](../../sessions/bs2026-figure3-python-hopf/)
  - [AUTO native Hopf continuation](../../sessions/bs2026-figure3-auto-hopf/)

  - [LOCA Moore--Spence Hopf continuation](../../sessions/bs2026-figure3-loca-hopf/)
  - [Figure 3 backend comparison](../../sessions/bs2026-figure3-backend-comparison/)
- The planning discussion resulted in the goal of doing true Hopf-locus
  continuation using LOCA. (Python and AUTO results were used mostly just for
  sanity checking.)
- The LOCA path was the most technically interesting part:
  - first, a real C++ NOX/LOCA backend foundation was added for the model;
  - then a runner was added for a `nox-loca-hopf-continue` command;
  - that command constructed LOCA's native Moore-Spence Hopf extended group;
  - $\log w$ was used as the Hopf bifurcation parameter;
  - $T$ was used as the locus direction.
