After mixed success with the Berton 2023 model, I looked around for a
different low-dimensional cloud model to play with, and found
<Cite>bergner-spichtinger-2026</Cite>. This paper introduces a different cloud
model and then does a range of dynamical systems investigations on it. This
seemed like a good vehicle to explore some of the numerical continuation tools
I've been looking at. I'm going to start off by replicating the results in the
paper using custom Python continuation code (as was used for the Berton 2023
model earlier), AUTO (which didn't work so well for Berton 2023) and the
[Trilinos LOCA
package](https://github.com/trilinos/Trilinos/tree/master/packages/nox#readme).
LOCA is a C++ package intended for performing this kind of analysis on very
large systems, and I've never had the patience to get it set up, because it's
quite complicated. Getting the agent to show me how to use it on a real but
small problem seems like a good way to go.

The first thing I did was to refine the `extract-model` model skill I
developed for the Berton 2023 model a little, and to use that to produce a
Python implementation of the core model in the Bergner & Spichtinger paper.
This is a 2-moment model for the ice-particle number concentration $n$ and the
ice mass concentration $q$, with an additional equation for the saturation
ratio $s$. The model extraction worked very well here. There were a couple of
ambiguous interpretations of things in the paper, where the authors said
something like "one could do ..." and the agent wasn't sure whether or not it
should do the thing, and there was one expression it couldn't OCR with high
confidence, but apart from that, everything went smoothly.

I've set things up in a [new
repository](https://github.com/ian-ross/bergner-2026) following the same
"episode"-based approach that I used for the Berton 2023 analysis, because
that seems to work quite well for this kind of semi-structured research
activity.

I validated the model implementation by getting the agent to reproduce [Figure
4 from the
paper](https://pubs.aip.org/view-large/figure/93440660/043115_1_5.0297531.figures.online.f4.jpg),
which has time series of some model trajectories for selected environmental
conditions, spanning a range of updraft velocities where the model displays
different behaviors: for sufficiently weak and sufficiently strong updrafts,
the model has a stable equilibrium, while for intermediate updraft strengths,
there is what appears to be a stable limit cycle.
