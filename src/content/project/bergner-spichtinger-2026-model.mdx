- Paper:
  - Hannah Bergner and Peter Spichtinger, **“Ice clouds as nonlinear oscillators”**, 2026.
  - Model target here: the low-dimensional ice-cloud microphysics/dynamics system, not the observational data archive.
  - Local working repository: `bergner-2026`.

- Starting point:
  - Extract the mathematical model from the saved publisher HTML/PDF.
  - Implement the core ODE right-hand side first.
  - Use Figure 4 as the initial qualitative reproduction target.

- Model state:
  - `n`: ice-particle number concentration.
  - `q`: ice mass concentration.
  - `s`: saturation ratio.

- Environmental/control parameters used for the Figure 4 reproduction:
  - `T = 225 K`.
  - `p = 300 hPa`.
  - `F = 1`.
  - `w ∈ {0.01, 0.1, 1.0} m s⁻¹`.

- Important interpretation choices:
