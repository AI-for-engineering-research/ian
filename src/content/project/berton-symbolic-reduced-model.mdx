The first symbolic question was deliberately modest: can a simplified version
of the <Cite>berton-2023</Cite> cirrus model explain why the numerical
solutions wobble? Not prove the full model has a sustained oscillation, but
identify the local feedback loop that might make oscillations plausible.

The answer is: **yes, as a mechanism guide**. The corrected reduced model has a
stable spiral equilibrium. In ordinary language, if the system is displaced
from its resting state, it circles back toward rest instead of returning in a
straight line. That is the right kind of local behavior to become a sustained
oscillation if some control parameter pushes the spiral from stable to
unstable.

The important caveat is equally important: this reduced calculation is not the
final verdict on the full Berton model. It is a map of where to look next.

## The reduced model

The reduced system keeps three quantities:

- altitude-like displacement `zeta`,
- vertical velocity `v`,
- ice-crystal radius `r`.

The model asks how vertical motion, fall speed, supersaturation, and radiative
growth couple near a resting state. An equilibrium is a self-consistent resting
configuration: the vertical velocity is zero, fall speed balances the ambient
updraft, and crystal growth balances the radiative term.

The useful simplification is that the local stability problem becomes a
three-by-three matrix. The signs in that matrix tell us whether a small
perturbation decays, grows, or spirals.

<Details summary="Mathematical details: corrected Jacobian and Hopf condition" variant="math">

The reduced variables are `(zeta, v, r)` and the corrected Jacobian at the fixed
point is

```text
J = [[ 0,   1,   0 ],
     [-a,  -k,  -b ],
     [-d,   0,  -c ]]
```

with

```text
a = k w
b = 2 k beta r*
c = (G / r*) R_r
d = (G / r*) (sigma_S + R_zeta).
```

The characteristic polynomial is

```text
lambda^3 + a2 lambda^2 + a1 lambda + a0
```

where

```text
a2 = k + c
a1 = k c + a
a0 = a c - b d.
```

The corrected Routh-Hurwitz Hopf condition is

```text
a2 a1 = a0,
```

or equivalently

```text
k*(k*c + a + c^2) + b*d = 0.
```

This is the executable SymPy result documented in the episode 2 analysis, not
a hand-derived expression.

</Details>

## The sign that changed the story

The most useful diagnostic is the combined gradient

```text
sigma_S + R_zeta = -5.640219674712e-05 m^-1.
```

For the corrected Case-0 reduced equilibrium this is negative. Combined with
the corrected sign in the Jacobian, that makes the equilibrium a stable spiral
rather than the saddle suggested by the erroneous hand derivation.

That distinction matters. A saddle is already unstable in a non-oscillatory
way. A stable spiral is different: it says the local physics naturally produces
a damped wobble, and a Hopf bifurcation would be the event where that wobble
stops damping and becomes self-sustaining.

The plot shows the real part of the slow complex eigenvalue pair as the drag

make the reduced model a useful mechanism finder.

## What this does and does not establish

This result establishes three things:

1. the reduced feedback loop is capable of spiral dynamics;
2. the corrected symbolic calculation points to a Hopf-capable sign structure;
3. executable symbolic algebra is essential, because a small sign error changes
the qualitative conclusion.

It does **not** establish that the full Berton model has a robust Hopf
bifurcation. The full model contains feedbacks and parameterization details
that the reduced calculation freezes or simplifies. That is why the next stage
was continuation: turn model parameters gradually and watch equilibria and
eigenvalues move.
